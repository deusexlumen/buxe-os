001 — Manifest

Ein Betriebssystem für deine Shell.

BUXE_OS ist kein Tool. Es ist keine App. Es ist ein PowerShell-Profil, das sich wie ein Spiel fühlt, wie ein Betriebssystem aussieht und wie ein lebendiger Code-Organismus handelt.

65+ Module. Casino. Arcade. Tower Defense. Text-Adventure. Desktop Pet. RPG-System mit 7 Companions. Ein verstecktes ARG. TTS-Stimmen. Und ein Boot-Screen, der dich jedes Mal begrüßt, als wärst du lange weg gewesen.

003 — Installation

In zwei Minuten daheim.

Klone das Repo in dein PowerShell-Profilverzeichnis. Sourcen. Fertig. Keine Admin-Rechte. Keine Registry. Nur dot-sourcing.

git clone https://github.com/deusexlumen/buxe-os.git $env:USERPROFILE\Documents\PowerShell

# Dann in dein Profil eintragen:
notepad $PROFILE

004 — Design

LucasArts Regeln.

Kein generischer Text. Keine game-over-Screens. Jede Zeile hat eine Stimme. Jeder Companion einen unveränderlichen Charakter. Fourth-Wall-Breaks sind Pflicht. Humor vor Drama. Und die 47 kommt immer wieder — aber nie zweimal am gleichen Ort.

Das System weiß, dass es Code ist. Die Charaktere wissen, dass sie in einer Shell leben. Und manchmal wissen sie mehr über dich, als du über sie.
